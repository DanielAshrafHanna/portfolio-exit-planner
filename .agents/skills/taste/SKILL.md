# Taste

## Overview

Use this skill for judgment, not decoration. The goal is to make the interface feel more confident by removing weak choices, strengthening hierarchy, and making the product easier to use.

## Taste Pass

1. Name the screen's job in one sentence.
2. Remove or reduce anything that does not help that job.
3. Strengthen the most important object on the screen.
4. Make adjacent elements feel related through spacing, alignment, and scale.
5. Replace vague copy with direct labels.
6. Prefer fewer, better visual ideas over many small flourishes.
7. Make a decisive recommendation when something should be removed.

## What Good Looks Like

- The screen is understandable before reading every label.
- Important data is visually prioritized without being loud.
- Repeated elements are consistent enough to build trust.
- Empty, loading, error, and stale states feel intentional.
- The UI has restraint: no unnecessary cards, text blocks, badges, gradients, or dividers.
- There is enough contrast between primary, secondary, and background surfaces.

## Taste Smells

Fix or remove these when found:

- text explaining the UI instead of the UI being clear
- too many competing accent colors
- decorative elements that make data harder to scan
- cards inside cards
- headers that are louder than the content they label
- buttons used where an icon, switch, input, tab, or menu would be clearer
- cramped tables with unclear column grouping
- visual polish that hides stale, missing, or risky financial data
