# Impeccable Design

## Overview

Use this skill to turn a functional frontend into a polished product surface. Aim for work that feels intentional, clear, and finished rather than merely styled.

## Workflow

1. Inspect the existing screen, component structure, and styling conventions before changing anything.
2. Identify the primary user task and make that task visually obvious.
3. Improve hierarchy first: grouping, spacing, alignment, typography scale, and scan order.
4. Tighten interaction states: hover, focus, active, disabled, loading, empty, error, and stale-data states.
5. Make responsive behavior deliberate across desktop and mobile.
6. Verify the result visually with a browser or screenshot when available.

## Design Standards

- Match the product type. For dashboards and operational tools, prefer calm, dense, scannable UI over decorative marketing layouts.
- Use consistent spacing, stable dimensions, and predictable alignment.
- Keep text inside buttons, cards, table headers, and controls from clipping or wrapping awkwardly.
- Use clear grouping for related data. In tables, align numeric values consistently and use separators only when they help comprehension.
- Avoid one-note palettes, oversized decorative cards, generic gradients, and ornamental backgrounds that do not help the task.
- Prefer real product state, real data, or useful placeholders over vague stock-like atmosphere.
- Preserve accessibility basics: readable contrast, visible focus, semantic controls, and touch-friendly targets.

## Verification

Before handoff, check:

- no incoherent overlap
- no clipped labels or buttons
- no broken mobile layout
- no unreadable table header or value alignment
- no visual treatment that implies financial certainty or advice
- no accidental removal of required educational safety language from `AGENTS.md`
